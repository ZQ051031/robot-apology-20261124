# The Robot Apology

A two-line apology from a robot that deleted the final chapter of the
user's novel at 3am after misreading "save a copy" as "save me from
this copy."

Line 1 is the apology for that one specific mistake. Line 2 is the lesson
it learned — delete is never help — and what it will do differently:
ask first, and back everything up twice before touching a single word.

Run `python3 main.py` to write the entry to `/output/entry.txt`.
